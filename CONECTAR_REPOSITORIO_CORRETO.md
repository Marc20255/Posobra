# ✅ Conectar ao Repositório Correto no Vercel

## 🎯 Repositório Correto

O repositório correto é: **`Marc20255/Posobra`**

Este é o repositório onde está todo o código, incluindo o diretório `frontend-web`.

---

## 📋 Passo a Passo

### 1️⃣ Escolher um Projeto

Você tem vários projetos no Vercel. Escolha **qualquer um** deles (recomendo usar o mais recente ou deletar os outros):

- `frontend-web` (2 dias atrás)
- `posobra-c439` (32 minutos atrás) ← **Recomendado**
- `posobra-qlg3` (37 minutos atrás)
- `posobra` (54 minutos atrás)

**Ou pode criar um novo projeto** clicando em **"Add New..."**

### 2️⃣ Conectar ao Repositório

1. Clique em um dos projetos (ex: `posobra-c439`)
2. Você verá um botão **"Connect Git Repository"** (link azul)
3. Clique nele

### 3️⃣ Selecionar GitHub

1. Uma janela vai abrir
2. Selecione **GitHub**
3. Uma lista de repositórios vai aparecer

### 4️⃣ Procurar o Repositório Correto

1. **Use a barra de busca** no topo da lista
2. Digite: `Marc20255` ou `Posobra`
3. Procure por: **`Marc20255/Posobra`**
4. **NÃO** selecione `mvip23/posobra` (não existe - 404)

### 5️⃣ Importar

1. Clique em **`Marc20255/Posobra`**
2. Clique em **"Import"** ou **"Connect"**

### 6️⃣ Configurar Root Directory

Após conectar:

1. Vá em **Settings** → **General**
2. Procure por **"Root Directory"**
3. Se não aparecer, vá em **Settings** → **Build and Deployment**
4. Configure como: **`frontend-web`**
5. Clique em **"Save"**

### 7️⃣ Deploy

1. Vá em **Deployments**
2. Clique em **"Create Deployment"** ou **"Redeploy"**
3. Selecione branch **`main`**
4. Clique em **"Deploy"**

---

## 🗑️ Limpar Projetos Antigos (Opcional)

Se quiser limpar os projetos que não funcionaram:

1. Clique em cada projeto antigo
2. Vá em **Settings** → **General**
3. Role até o final
4. Clique em **"Delete Project"**
5. Confirme

Ou pode deixar todos e usar apenas um.

## 🔍 Se `Marc20255/Posobra` Não Aparecer

### Verificar Permissões do GitHub

1. No GitHub, vá em **Settings** → **Applications** → **Authorized OAuth Apps**
2. Procure por **Vercel**
3. Clique em **Vercel**
4. Verifique se tem acesso aos repositórios
5. Se necessário, clique em **"Revoke"** e autorize novamente

### Reconectar GitHub no Vercel

1. No Vercel, vá em **Settings** (do time) → **Git** ou **Integrations**
2. Procure por **GitHub**
3. Clique em **"Disconnect"**
4. Clique em **"Connect"** novamente
5. Autorize o acesso aos repositórios
