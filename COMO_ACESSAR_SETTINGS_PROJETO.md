# 📍 Como Acessar Settings do Projeto (NÃO da Equipe)

## ⚠️ IMPORTANTE: Você está no lugar errado!

Você está em **"Team Settings"** (Configurações da Equipe), mas precisa estar em **"Project Settings"** (Configurações do Projeto).

---

## ✅ Passo a Passo Correto

### 1️⃣ Voltar para o Projeto

1. **No topo da página**, você vê: `General - Team Settings - Dashboard`
2. **Clique em "Dashboard"** ou no **logo do Vercel** (triângulo preto) no canto superior esquerdo
3. Isso vai te levar de volta ao dashboard principal

### 2️⃣ Encontrar o Projeto "posobra"

1. No dashboard, você verá uma lista de projetos
2. **Procure e clique no projeto "posobra"**
3. Isso vai abrir a página do projeto

### 3️⃣ Acessar Settings do Projeto

1. **No menu superior** (onde está "Overview", "Deployments", etc.)
2. **Clique em "Setting"** ou **"Settings"** (geralmente é o último item do menu)
3. **NÃO** clique em "Team Settings" - isso é diferente!

### 4️⃣ Encontrar Root Directory

1. Dentro de **Settings do Projeto**, você verá um **menu lateral à esquerda**
2. Clique em **"General"** (primeiro item)
3. Role a página para baixo
4. Procure por **"Root Directory"** ou **"Project Root"**
5. Pode estar em uma seção chamada **"Build & Development Settings"**

---

## 🎯 Resumo Visual

```
Vercel Dashboard
  └── Clique em "posobra" (projeto)
      └── Menu superior → "Setting" ou "Settings"
          └── Menu lateral → "General"
              └── Role para baixo → "Root Directory"
                  └── Altere para: frontend-web
                      └── Save → Redeploy
```

---

## 🔍 Diferença Importante

- ❌ **Team Settings**: Configurações da sua equipe/conta (onde você está agora)
- ✅ **Project Settings**: Configurações do projeto específico "posobra" (onde você precisa estar)

---

## 📋 Checklist

- [ ] Voltar ao Dashboard (clicar no logo do Vercel)
- [ ] Clicar no projeto "posobra"
- [ ] Clicar em "Setting" ou "Settings" (no menu superior do projeto)
- [ ] Clicar em "General" (no menu lateral)
- [ ] Procurar "Root Directory"
- [ ] Alterar para `frontend-web`
- [ ] Save → Redeploy
